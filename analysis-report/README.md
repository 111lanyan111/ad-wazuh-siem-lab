## 报告结构

每份报告包含以下章节：

1. **执行摘要** - 关键发现、风险评级、建议
2. **攻击场景描述** - 攻击前提、攻击路径、攻击目标
3. **ATT&CK 映射** - 战术、技术、子技术
4. **攻击复现步骤** - 详细操作步骤、命令、工具
5. **日志与告警分析** - 关键 Event ID、Sysmon 事件、Wazuh 告警
6. **IOC 指标** - IP、域名、文件哈希、注册表项等
7. **检测规则** - Sigma 规则、Wazuh 规则、检测逻辑
8. **误报分析** - 可能的误报场景、调优建议
9. **缓解措施** - 技术防护、配置加固、监控建议
10. **附录** - 参考链接、工具列表、术语表

## 报告编写规范

- **数据真实**：所有日志样本、告警截图来自实际攻击复现
- **可复现**：攻击步骤详细到可直接复制执行
- **可检测**：每条检测规则都有对应的日志样本验证
- **风险量化**：使用 CVSS 或自定义风险矩阵评级
- **建议可执行**：缓解措施具体到配置命令或策略

## 输出格式

- 主报告：Markdown 格式（便于版本控制和转换）
- 附件：Wazuh 告警导出 JSON、日志样本 CSV、规则文件
- 演示：Wazuh Dashboard 截图、攻击时间线图
